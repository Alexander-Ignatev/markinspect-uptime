# markinspect-uptime

Внешний мониторинг стенда MarkInspect: GitHub Actions проверяет
`https://markinspect.aignatev.ru/health` каждые 5 минут **со своих раннеров**, то есть
независимо от сервера приложения.

| Событие | Что происходит |
| :--- | :--- |
| `/health` отвечает `{"status":"Healthy"}` | ничего |
| три неудачи подряд (интервал 20 с) | открывается issue «MarkInspect: /health не отвечает», GitHub присылает письмо владельцу |
| проверка снова проходит | бот комментирует и закрывает issue |

Репозиторий публичный только ради бесплатных минут Actions — секретов и кода приложения
здесь нет.

## Ручной прогон

Actions → **uptime** → *Run workflow* (можно подставить другой URL в поле `url`).

## Ограничения

- Расписание GitHub работает по принципу «лучшее усилие»: задержка обычно 1–5 минут,
  иногда больше. Для шага в 1 минуту и SMS/Telegram лучше UptimeRobot (free) —
  этот репозиторий останется вторым независимым каналом.
- GitHub отключает расписания после 60 дней без активности в репозитории, поэтому
  workflow `keepalive` раз в месяц коммитит `.keepalive`.
- Алерт приходит письмом GitHub: проверьте, что уведомления на
  `Alexander-Ignatev` включены (Settings → Notifications → Issues).
